HTML, Mermaid, PDF & image viewers

Orca includes built-in viewers for the formats that show up in most repos.

HTML

Open a local, SSH, or paired-runtime .html file with Open in Orca Browser or Open Preview to the Side. Orca renders the document locally in a sandboxed browser tab and reads the file and its relative assets through the workspace's file connection, so a remote design document stays crisp without exposing your desktop filesystem.

The preview asks before reading additional folders, and grants only the folders you approve for that tab. External HTTP(S) links require confirmation and open in a normal Orca browser tab; downloads are disabled inside document previews. Pages that request web fonts from a provider you have authorized — for example a Google Fonts link — render them instead of falling back. Use Preview options to reload from disk, open the source file, or copy its full or workspace-relative path.

The preview's document chip doubles as an address bar. Edit it and enter a web URL to turn that tab into a normal browser tab; enter a workspace HTML path from a browser tab to turn it back into a preview. Back crosses between the two when there is no intervening page history.

On paired runtimes, the HTML file must be inside the worktree. Very old paired servers may render the document without binary assets; update the server if remote images do not load.

Mermaid

Mermaid diagrams render inline inside markdown preview. Standalone .mmd files open in a dedicated viewer with pan/zoom.

PDF

PDFs open fit to the preview pane width unless you have saved another zoom; fit-to-width adjusts when you resize the pane. You can scroll, zoom, and select text. Pinch on a trackpad, Ctrl+scroll, or Cmd/Ctrl with = / - / 0 zooms the page and keeps the spot under your cursor. Orca remembers your PDF zoom across tabs and restarts. Scroll position is restored when you switch away from a PDF tab and come back (including close-and-reopen in the same session) — page plus mid-page offset, so you land where you left off. Positions are session-only and clear when Orca restarts.

Images

.png, .jpg, .svg, .webp, .gif. Image-diff mode compares two versions of the same file side-by-side.

Audio & video

Audio and video files play inside Orca with native controls — .mp3, .wav, .ogg, .m4a, .aac, .flac, .mp4, .mov, .webm, .mkv, and .avi. The desktop streams local, SSH, and paired-server previews, so a large clip starts playing without loading the whole file first, and a local file offers Open in Default App when you want your OS player instead. A file Orca cannot decode reads as a playback error rather than a blank pane.

CSV / TSV

.csv and .tsv files open in a table you can edit in place. Click a cell to edit it, select and copy/paste ranges, and use the row and column menus to add or remove rows and columns; the Columns menu reorders them. Sort or filter to inspect the data — that view never rewrites the file's row order — and whole-cell http(s) links open on click. The file stays the source of truth: edits preserve its BOM, record endings, quoting, and final newline. Column widths you set are remembered across view switches and app restarts. Useful for fixtures, exports, and any tabular data checked into the repo.

The viewer auto-detects the delimiter (comma, semicolon, or tab), and a Delimiter picker lets you force Auto, Comma, Semicolon, or Tab — useful for semicolon-separated exports. Use the toolbar to switch to the raw text view.

Files of 1 MiB or larger open as a read-only paged preview: Orca indexes the file and renders only the rows and columns on screen, so a large export stays responsive without loading it all into memory. Table edits must stay under that size — switch to the raw text view for larger files.

Jupyter notebooks

Open a .ipynb file to read rendered markdown, code cells, and saved outputs. Click a code cell to edit it; double-click a markdown cell or press Enter to edit its source. Edits save to the notebook file while preserving nbformat.

For local Python notebooks, run cells with Shift+Enter to advance or Cmd/Ctrl+Enter to stay on the cell. From the first run until you close the tab, Orca keeps a Jupyter kernel for that notebook, so variables persist between cells. Plots, rich outputs, errors, and execution counts appear with the cells. Use the notebook header to Run All, Interrupt, Restart, or Clear All Outputs.

The kernel picker in the header recommends a nearby .venv or .conda environment. You can choose another Python or browse for one; Orca remembers the choice for that notebook. Python needs ipykernel and jupyter_client. If ipykernel is missing, Orca offers to install it. When the selected Python blocks package installs, choose Create .venv to set up a workspace environment instead. The setup dialog shows progress and errors.

Before running notebook code, confirm Orca's trust prompt. Orca does not start a workspace Python interpreter until you trust the notebook. Notebooks in SSH worktrees and notebooks in other languages can still be viewed and edited. See File explorer to find notebooks in your worktree.
