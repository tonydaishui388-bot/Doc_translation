Monaco editor & autosave

Orca's code editor is Monaco — the same editor VS Code uses — with a few Orca-specific tweaks.

Autosave

Files save on blur and after short idle periods. There is no "dirty" dot because there are no unsaved changes in normal flow.

Before each save, Orca checks that the file has not changed on disk since the tab last read or wrote it. If it has, autosave pauses and the changed-on-disk banner lets you compare, reload, keep your edits, or explicitly overwrite the disk version. Your edits stay in the tab until you choose.

Format on save

Turn on Settings → General → Editor → Format on Save, then configure a formatter command and include patterns for each project and choose Save formatter. The formatter reads the file text from standard input and writes the formatted text to standard output; do not use a write-to-file flag. You can use ${file} or ${relativeFile} in its arguments. Formatting runs on manual saves and autosave for matching files.

If the formatter fails, Orca shows a notice and saves the original text. Formatters do not run on SSH-hosted files yet; a configured SSH formatter shows a notice and saves the original text. Only configure commands you trust.

Per-host editor state

Files with the same path on different hosts keep separate editor text and Undo history, so opening a remote file that shares a path with a local one can't expose the other's Undo stack. Tabs for the same local file still share one model.

Multi-cursor, go-to, find

  • Cmd-D — select next occurrence.
  • Cmd-F / Cmd-Shift-F — file find / worktree find. File find seeds the search box from the current selection when text is selected.
  • Cmd-Click — go to definition (where supported by language extensions).

Git blame

The Git blame status item shows the author and date for the line at your cursor. In a repository workspace, select it to open the commit. Turn on Inline git blame under Settings → Editor to show annotations beside your code.

Changes view mode

Toggle Changes view mode in any editor tab to flip the file into an in-tab HEAD-vs-working-tree diff without leaving your cursor position. Same shortcuts as the Diff viewer — n/p to walk hunks, s to stage. Toggle again to return to the regular file view.

Word wrap

File editors wrap long lines by default. Toggle Word Wrap from the editor tab's ⋯ menu, press Alt+Z (same as VS Code; remappable under Settings → Shortcuts), or set the default under Settings → General → Editor Word Wrap. This setting is separate from Diff Word Wrap, which only affects diff editors.

Minimap

A minimap is available in the file editor under Settings → Appearance. It's off by default; turn it on if you prefer the VS Code-style overview rail.

Custom editor font

By default the editor and diff views use the same font as the terminal. Leave Editor Font Family empty under Settings → Appearance to keep that link; set a font to override editors only (UI font stays separate).

Language support

Syntax highlighting ships for the languages Monaco supports out of the box, plus extras such as Solidity, Twig templates, Quarto (.qmd), R Markdown (.Rmd), and shell startup dotfiles such as .bashrc and .zshrc. Nim and Typst are highlighted through Orca's shared TextMate grammar layer, so a single very long line cannot freeze the window. Orca is intentionally editor-first, not IDE-first — run type-checkers and linters in a terminal pane.
